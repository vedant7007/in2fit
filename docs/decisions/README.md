# Decision records

One file per decision that cost time to make and would cost more to make again. They record
**why**, the evidence, and what was ruled out — not what the code does. A record is written
when the decision is taken, and corrections are appended and dated rather than edited in
place, so the reasoning can be read in the order it happened.

Numbered from `0001`. Two files share the number `0026` (`0026-code-mixed-food-words.md` and
`0026-the-spoken-turn-on-screen.md`): two sessions claimed it within a minute of each other
and the collision is recorded rather than quietly renamed, because both numbers are cited by
name elsewhere. Later collisions were resolved by renaming the later file (`0022` to `0031`,
`0028` to `0034`).
