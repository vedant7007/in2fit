# Decision records

One file per decision that cost time to make and would cost more to make again. They record
**why**, the evidence, and what was ruled out — not what the code does. A record is written
when the decision is taken, and corrections are appended and dated rather than edited in
place, so the reasoning can be read in the order it happened.

Numbered from `0001`, and a number is claimed in `COORDINATION.md` before the record is
written, because two sessions once claimed the same one within ten minutes. Three such
collisions happened and all three were resolved the same way: the LATER record was renumbered
to the next free number and every inbound reference updated (`0022` to `0031`, `0028` to
`0034`, and on 22 September `0026-code-mixed-food-words` to `0041`). The earlier record keeps
its number, because it is the one already cited by number in the code and the working log.
