# Screenshots

Dated folders, one per screenshot session, of real builds on a real emulator or phone. They
exist as evidence: a claim in a document or on a slide can be checked against the screen it
came from. Nothing here is a mockup.

| folder | what it shows |
| --- | --- |
| `2026-09-20-shell/` | the first working shell: the four demo beats, the About screen, the pre-flight card |
| `2026-09-20-ira/` | the same build after the design system landed |
| `2026-09-21-ira/` | the v2 interface rebuild, including the hostile-read passes over fonts, Devanagari and long text |

The screens are from a build with seeded demo data where the file name says so. A screenshot
is not a measurement: timings come from the logs named in `docs/demo/` and `docs/design/measurements/`.
